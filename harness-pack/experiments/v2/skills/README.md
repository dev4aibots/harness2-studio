## Available Skills

### debugging
- Purpose: Systematic debugging of failing code
- Steps: Reproduce → Isolate → Hypothesize → Test → Fix → Verify
- When: Any time code doesn't behave as expected

### refactoring
- Purpose: Improve code structure without changing behavior
- Steps: Identify smells → Extract methods → Rename → Simplify → Test
- When: Code is duplicated, complex, or hard to read

### optimization
- Purpose: Improve performance of existing code
- Steps: Profile → Identify bottlenecks → Optimize → Verify
- When: Performance requirements are not met

### documentation
- Purpose: Write clear, comprehensive documentation
- Steps: Identify audience → Document purpose → Document usage → Document examples
- When: Any public API or complex internal logic

### testing
- Purpose: Write comprehensive test suites
- Steps: Identify test cases → Write AAA tests → Run → Fix failures
- When: Any new functionality

## Skill Invocation Pattern
1. Select the appropriate skill for the task
2. Provide context and constraints
3. Execute the skill
4. Review and apply results
5. Iterate if needed
